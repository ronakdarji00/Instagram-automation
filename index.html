Meta Token Renewal Guide

Instagram tokens expire every 60 days. Follow these steps to generate a fresh token:

1

Open Meta Graph API Explorer

Visit Meta Graph API Explorer and select your Facebook App.

2

Select Permissions (Comments & DMs)

Select User/Page Token and add: instagram_basic, instagram_manage_comments, instagram_manage_messages, and pages_show_list.

3

Extend to 60-Day Long-Lived Token

Generate token, copy it into Access Token Debugger and click "Extend Access Token".

4

Update Render Environment

Render Dashboard → instagram-automation-backend → Environment → Edit IG_ACCESS_TOKEN and paste the new token.
