Meta Token Renewal Guide

Instagram tokens expire every 60 days. Follow these steps to generate a new one:

1

Open Meta Graph API Explorer

Visit Meta Graph API Explorer and select your Facebook App.

2

Select Permissions

Under "User or Page", select your User Token or Page Token. Ensure permissions include instagram_basic, instagram_manage_comments, and pages_show_list.

3

Extend to 60-Day Long-Lived Token

Click "Generate Access Token", then copy it to the Access Token Debugger and click "Extend Access Token".

4

Update Render Environment Variables

Go to your Render Dashboard → Service instagram-automation-backend → Environment → Edit IG_ACCESS_TOKEN and paste the new token.
