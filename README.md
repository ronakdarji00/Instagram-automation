# Instagram Auto-Reply — Frontend

A modern dark-themed dashboard to control the Instagram auto-reply backend. Deploys to Vercel.

## Features

- **Dashboard** — live stats and recent activity
- **Manual Run** — trigger replies with one click
- **Activity** — full history of replied comments
- **Settings** — connect Render backend URL and API key
- **No database** — all data stored in browser localStorage

## How to use

1. Deploy backend on Render from `Instagram-automation-backend` repo
2. Set backend URL and API key in Settings
3. Go to **Manual Run** and click **Run Auto-Reply**

## Deploy to Vercel

1. Push this repo to `https://github.com/ronakdarji00/Instagram-automation`
2. Import to Vercel
3. Framework: **Other**
4. Deploy
